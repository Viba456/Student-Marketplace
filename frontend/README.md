# Frontend (static)

This is a minimal static frontend that interacts with the backend auth API at `http://127.0.0.1:8000/auth`.

Run a static server from the `frontend/` folder and open the page in your browser:

```bash
cd frontend
# Python 3 built-in server on port 3000
python -m http.server 3000
# then open http://127.0.0.1:3000 in your browser
```
