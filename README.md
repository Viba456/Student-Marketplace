# Student Skill Marketplace

## Overview
The Student Skill Marketplace is a web-based platform designed for students to offer their skills and discover skills offered by other students. It creates a trusted, campus-focused environment where students can earn money, build portfolios, and collaborate with peers.

## Project Purpose
This project addresses the gap between student talent and real opportunities. It provides a student-only marketplace that is:
- easy to use
- affordable for small tasks
- built around trust and campus identity
- suitable for tutoring, design, coding, content creation, editing, and other student services

## Core Objectives
- Help students showcase their skills through structured profiles
- Enable students to earn while studying
- Encourage collaboration across departments and skill areas
- Help students build portfolios and professional experience

## Main Modules
The platform is structured into the following modules:

1. User Registration / Login
   - Secure student sign-up
   - Email verification
   - Password recovery and account management

2. Student Profile Management
   - Personal details and academic information
   - Skills and proficiency levels
   - Profile picture and ratings summary

3. Skill Listing Module
   - Create and manage service listings
   - Add descriptions, price, and sample work
   - Edit, pause, or remove listings

4. Service Request System
   - Search and filter listings
   - Book services and track request status
   - Manage requests from requested to completed

5. Payment Module
   - Secure payments between students
   - Transaction record generation
   - Safe payment release after completion

6. Rating and Review Module
   - Feedback after completed services
   - Reputation building through ratings
   - Reporting and dispute handling

7. Admin Panel
   - User management
   - Listing moderation
   - Dispute resolution and platform statistics

## Technology Stack
- Frontend: React.js
- Backend: Python with FastAPI
- Database: MySQL
- Development Tools: VS Code, Postman, Git, MySQL Workbench

## Project Workflow
1. Student registers and verifies identity
2. Student creates a profile
3. Student adds available skills/services
4. Other students browse or search listings
5. A request is made to book a service
6. The work is completed and delivered
7. Both parties provide ratings and feedback
